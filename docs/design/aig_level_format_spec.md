# AIG Level 文件格式 v1.0

一份 `.level` 文件对应一张 AIG（ABC DOT 或两输入组合 BLIF）。最常见的用法是只列出需要非零初始层级的主输入（PI）。有完整层级报告时，同一份文件也可以记录输入、内部节点和输出的到达层级、要求层级和裕量。三个指标沿用网表 Timing 中 AT、RT、Slack 的含义，单位为整数逻辑级。[Timing 格式规范](timing_format_spec.md)

## 只给输入指定初始层级

以下就是一份完整的 `design.level` 文件。每行写一个输入名和它的 AT level，表头可省略。

```text
a       3
bus[0]  1
```

这表示 `a` 从第 3 级起算，`bus[0]` 从第 1 级起算，其余 PI 从 0 起算。RT 和 Slack 均可省略。需要表头时，写 `point at_level` 即可。

如果 `g = AND(a, b)` 且 `b` 未列出，则 `g` 在第 4 级。每经过一个 AND，在两个输入层级的最大值上加 1。反相边和输出端口各增加 0 级，常量从 0 起算。

## 记录 AT、RT 和 Slack

带表头时可以只选需要的指标。下例给一份 BLIF 中的输入 `n0`、内部信号 `n2` 和输出 `n3` 填写层级数据。[配套 BLIF 文件](../../examples/aig_mapped_names.blif)

```text
point  at_level  rt_level  slack_level
n0     3         -         -
n2     4         6         -
n3     4         3         -1
```

| 字段 | 含义 | 取值 |
| --- | --- | --- |
| `point` | AIG 中的对象名 | 区分大小写 |
| `at_level` | 该点的到达层级。填在 PI 上时，同时指定它的初始层级 | 非负整数 |
| `rt_level` | 该点最晚允许到达的层级 | 整数 |
| `slack_level` | 该点的层级裕量。负值表示比要求晚到 | 整数 |

与 Timing 相同，显式填写的指标按报告原值保留。若同一点给出 AT 和 RT 并省略 Slack，则取 `slack_level = rt_level - at_level`。示例中 `n2` 的裕量为 2，`n3` 的裕量为 −1。只给 RT 可用表头 `point rt_level`，只给 Slack 可用 `point slack_level`，其余报告指标保留为空。

PI 的 AT 是拓扑层级计算的起点。内部节点和输出上的 AT、RT、Slack 是该点的报告值，即使与图上推算值有差异也原样保留。例如用上例的 PI 层级推得 `n2` 在第 4 级。若外部报告写 `n2 5 6 -`，该点的报告 AT 为 5，报告 Slack 为 1，拓扑层级仍为 4。

## 文件读写约定

- **文本。** 使用 UTF-8，每行一条记录。列之间用空格、Tab 或逗号分隔。忽略空行和以 `#` 开头的整行注释。名称含空格、逗号或以 `#` 开头时，用双引号包围。名称中的双引号写成两个双引号。
- **列。** 无表头的两列固定为“PI 名、初始 AT”。带表头时，首个有效行包含 `point` 和至少一个指标列，列顺序可调。每条数据与表头列数一致，缺项写 `-`，每行至少给出一个数值。数值使用十进制整数。
- **识别。** 推荐后缀 `.level`。粘贴或使用通用 `.txt`、`.csv` 文件时，带 `at_level`、`rt_level` 或 `slack_level` 的表头可直接识别。一份已经明确为 Level 的文件也可使用 Timing 风格的短列名 `at`、`rt`、`slack`。
- **对象名。** 使用 BLIF 的源信号名、已唯一绑定的映射名，或 ABC DOT 的源节点 ID、标签。按完整名称匹配，保留 `/`、`[]` 等字符。两列简写接受 PI 的源名、标签以及直接映射到该 PI 的名称。带表头时优先匹配端口，再查内部驱动节点。BLIF 内部缓冲或反相信号折叠到 PI 时，其名称可用来为驱动对象填写报告。要指定初始层级，请填写 PI 自身的名称或其直接映射名。可选的 `kind` 列接受 `pi`、`and`、`po`、`constant`，用于同名时指定对象类型。
- **校验与替换。** 一份文件内，同一对象的不同指标可以分行填写。同一指标重复且同值时合并，不同值时报出冲突行。未知列、非法数值、找不到对象或匹配不唯一时，给出文件名、行号及原因。新文件完整校验通过后才替换该图的上一份 Level 数据，省略的 PI 恢复默认初始层级。
