# AIG 重收敛路径与逻辑块识别实施计划

日期：2026-11-17。状态：计划及效果图已确认，P1–P5 实现、检视修复及用户验收完成，已随 `v1.5.2` 推送；mapped 首轮超时及独立复测记录见下文。

本轮为 AIG 增加全图结构重收敛分析，以及 XOR2、XNOR2、MUX2 全变体识别。用户通过结果列表定位路径和逻辑块，查看引脚、极性与来源；原始 AND/反相边拓扑保持不变。本计划对应 [AIG 后续需求](aig_followup_roadmap.md) 的 F-AIG-03、F-AIG-04，不依赖尚未交付的 AIG Compare 或 Netlist → AIG。

## 1. 已确认范围

| 能力 | 本轮交付 | 范围边界 |
| --- | --- | --- |
| 结构重收敛 | 全图结果列表，分叉点与汇合点，路径定位和高亮 | 组合有向无环图；不做逻辑可激活性、毛刺或实际时序分析 |
| XOR2 / XNOR2 | 全部输入置换、输入反相、输出反相变体 | 两个有效边界输入；保持真实输入输出极性 |
| MUX2 | 二选一结构，全部引脚角色排列、选择端及数据端反相、输出反相变体 | 三个有效边界输入；显示 S、D0、D1 和输出极性 |
| 图形联动 | 类型标签、可筛选结果列表、节点及边高亮、Inspector 详情 | 不替换 AND 节点，不增加折叠、抽象门视图或新布局模式 |
| 一致性 | Standard / ABC、工作区恢复、SVG 导出使用同一分析结果 | 本轮仅接入现有 AIG Single / Whole，接口保留工作区隔离 |

“全部变体”包含输入置换、输入/输出反相及等价的德摩根表达。实现以局部布尔函数校验为依据，不依赖节点名称、声明顺序、坐标或某一种画法。

有限的是函数类别，同一函数可有任意大的冗余 AIG 实现。完整性承诺分为两层：候选范围内完整识别全部目标函数变体；候选子图搜索采用明确预算并报告覆盖情况，不能将预算裁剪后的“未发现”解释为全图不存在。

## 2. 重收敛结果定义

一个普通结果由 `(stemId, mergeId)` 标识。stem 是非恒定 PI 或 AND 输出，merge 是 AND；两者之间存在两条内部节点不相交的有向路径，且从 stem 的不同出边出发。只共享祖先、同处一条长路径或单纯高扇出，均不足以成立。

- 同一 stem 可以对应多个 merge；嵌套与重叠结果分别保留。
- 两条分支已经汇合后的公共尾段不产生新的同源结果；若再次分叉并汇合，按新的分叉点识别。
- 同源信号直接接入同一 AND 的两个输入槽位列为退化连接，默认不计入普通重收敛；原始边及槽位身份保留。
- 常量源默认不作为 stem。反相边参与结构追踪，极性不影响结构可达性。
- 结果包含两个确定性选择的见证路径。选中时可展示该 stem→merge 的路径子图，并区分两条见证路径；额外路径作为同一结果的其他路径显示，不穷举所有路径组合。
- 路径高亮只包含通往该 merge 的相关边；旁路外部负载和汇合后的边不进入路径高亮。按需提取路径子图时同样报告完整或受限状态。
- 路径长度使用 AND 级数或边数，界面必须明确单位，不能称为时间延迟。

结果摘要至少包括：结果 ID、stem、merge、两条见证路径长度、重叠逻辑块关联及详情是否就绪。涉及节点/边数量只有在对应路径子图计算完成后才显示精确值。

## 3. 逻辑块识别与全变体验收

### 3.1 变体集合

| 家族 | 穷举操作 | 变换组合数 | 去重后的函数数 |
| --- | --- | ---: | ---: |
| XOR2 / XNOR2 | 2! 输入排列 × 2² 输入反相 × 2 输出反相 | 16 | 2 |
| MUX2 | 3! 输入排列 × 2³ 输入反相 × 2 输出反相 | 96 | 24 |

以上计数按固定命名、彼此独立的边界变量计算，作为验收生成器的预期值，不是某个设计的块数量。MUX2 指两个数据输入加一个选择输入。

### 3.2 候选与判定

1. 完整枚举常规三 AND 实现的槽位排列与极性，作为快速识别路径；共享内部节点不使候选失效。
2. 对各根节点进行有界的两/三叶 cut 搜索，补充局部重写和不同德摩根形式；叶节点可以是内部信号，不限于 PI。
3. 将叶节点作为独立布尔变量，计算 4 或 8 行真值表，对目标函数集合精确匹配。不能用整个电路中的输入相关性或 don't-care 假设制造匹配。
4. 返回确定性的引脚角色、输入反相位和输出反相位，附带实际子图节点/边与边界映射。
5. 验收同时覆盖 16 / 96 个变换组合；每种组合校验分类、引脚映射、反相位及全行真值，不只检查一个类型标签。

候选数量、cut 大小、局部节点数、访问边次数、返回结果数及总体工作预算由分析策略统一拥有。P1 基准阶段确定数值，并写入同一策略模块与验收数据；UI 和算法不能各自设隐含阈值。常规三 AND 的全部变体应走固定局部检查，不因 cut 优先级而遗漏。

### 3.3 极性、重叠和计数

- 块输出使用 `(rootId, outputInverted)` 表示，不以外部信号名称决定逻辑类型。
- XOR/XNOR 以根节点正相、规范化非反相边界变量的函数确定主类型；反相使用在详情中显示对应另一类型，不生成第二个物理块计数。
- MUX 允许反相输出，必须同时展示“根节点函数”和选定输出用途，避免把反相 MUX 标成普通正相 MUX。
- 交换 S 极性与 D0/D1、整体反相与数据端反相等重复描述，规范化成同一结果。规范化排序独立于原数组和源码声明顺序。
- 同一物理子图、同一根和同一无符号边界集合仅保留一个规范结果。不同合法边界可保留为不同候选，并在同一根下分组；摘要区分候选数与唯一根数量，不能将重叠候选数量解释为不相交电路分区。
- 允许多个块共享节点或边，详情显示外部负载和关联块；高亮不吞掉共享连接。
- 常量或重复输入按实际有效输入和函数分类。退化为 XOR/XNOR 时归入相应类别；退化为 BUF/INV、AND/OR、常量时不计为普通 MUX。XOR/XNOR 优先于特殊 MUX 描述。

## 4. 界面方案

沿用现有 Navigator—AIG 画布—Inspector 三栏，不新增独立分析页面。

| 位置 | 新增内容与行为 |
| --- | --- |
| Navigator | 增加 Analysis 页，内含“重收敛”和“逻辑块”两个结果类别；显示数量、完成状态、分页与类型筛选 |
| 结果行 | 显示端点或类型/根节点；单击选择并高亮，保持当前视口；独立“定位结果”操作才适配视口 |
| 画布 | 保持 PI/PO 三角、AND 椭圆、BT 方向和曲线；根旁小标签显示 XOR/XNOR/MUX；选中块显示成员高亮 |
| 重收敛 | 分叉点与汇合点有文字角色；两条见证路径使用不同颜色和 A/B 标记，反相边继续使用虚线 |
| Inspector / Analysis | 结果端点、两条见证路径，或块公式、S/D0/D1 与输入输出极性、成员、外部共享及关联结果 |
| 状态反馈 | 分开显示未分析、分析中、完成、部分结果、取消和失败；部分结果数量明确标注“已发现” |

重收敛与块结果可互相跳转。例如选择 XOR 块，可查看其输入在块根处的重收敛；选择重收敛结果，可查看覆盖该区域的块。

高亮优先级：对象选中外环独立保留；活动分析使用外层 halo/路径描边；原有关键路径及扇出状态仍在详情中可见。邻接高亮与分析高亮冲突时采用一致策略，不能覆盖反相线型。标签是展示覆盖层，不改变节点尺寸和 Graphviz 输入，不因开关标签重新布局。

方案阶段的效果图用于验证结果入口、列表—图形—详情联动，以及极性/共享信息是否易读。图中数据为人工构造示例；实现后的正确性和几何验收以第 8 节测试记录为准。

## 5. 数据边界与调度

新增计算位于 `src/domains/aig/`，建议按索引、重收敛、块识别和结果查询拆分；文件命名沿用 snake_case。现有 `aig_analysis.js` 的轻量统计不承担无界搜索。

```text
不可变 AIG model
  -> 共享拓扑与槽位索引
  -> 重收敛分析 / 逻辑块分析
  -> 版本化分析产物与按需路径详情
  -> 查询接口 -> Navigator / Inspector / Scene 高亮
```

分析产物包含 `version`、源文档修订、策略指纹、完成状态、搜索/截断诊断和结果集合。模型及现有导入产物保持不可变；大型索引、路径集合、Worker 和闭包只存放于运行时产物。

会话仅保存分析类别、筛选、选中结果、标签/高亮偏好。恢复后按文档修订重新获取或计算结果；结果 ID 无效时安全清除分析选区，不破坏原对象选区和视口。

任务调度通过 `application/` 的现有协调与取消边界。导入和首帧显示不等待扩展分析完成；分析在工作区可用后启动，可取消，旧文档或旧策略的迟到结果不能覆盖新工作区。公共层只调用领域贡献，不增加 AIG 硬编码分支；`main.js` 不增加算法或直接调度。

### 实现预算与实测

默认每类分析工作量 800 万；每节点 16 个 cut（包含平凡 cut），cut 缓存 25 万；候选块最多 32 个 AND；每类最多返回 2000 个结果；单分叉向后搜索 4096 个节点，证明路径存储 20 万项；按需路径并集 200 万工作量 / 2 万节点，缓存 8 份详情。Worker 硬超时 15 秒。确定性预算决定 `partial`，超时显示失败，不将时间截断结果伪装为完整。

Linux / Node 24.16.0 下，`npm run benchmark:aig-structure` 的深链、高扇出、密集重收敛、奇偶链、MUX 链共 20 个用例：

| 规模 | 分析耗时范围 | 堆增量范围 |
| --- | --- | --- |
| 1K | 13–1865 ms | 0–35 MiB |
| 4K | 38–3875 ms | 7–40 MiB |
| 10K | 96–5207 ms | 10–52 MiB |

全部未触及 15 秒硬超时；密集及大规模用例按预期返回部分结果和具体截断原因。这是算法独立实测，不含 Graphviz 布局时间；不是任意拓扑的耗时承诺。默认网表 `npm run benchmark` 使用 `DEFAULT_LAYOUT_PROVIDER_ID`（实测报告为 `native-layered`），1024 / 4096 / 8192 cells 均 routed、零违规。

### 代码检视修复（2026-11-17）

六处问题均先通过新增回归用例复现，再修复：

1. 重收敛见证路径预算恰好耗尽、进入下一个分叉点时，遗漏了 `witness-limit`，导致未完整搜索却显示 complete；同时修正拒收路径时的存储计数。
2. 首次分析取消或失败且尚无结果时，切换同文档视图会自动重启；现在保留停止状态，显式重试才重启。
3. 详情失败后切换到缓存结果、清除选区或重新分析，会遗留上一结果的错误提示；现在按请求和结果重置。
