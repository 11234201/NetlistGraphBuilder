# 界面与交互设计规范

## 产品体验原则

本项目是面向芯片综合与验证工程师的专业分析工具，而非营销展示页。打开页面后的第一屏即直接进入可操作的工作台：

- **全局栏**：`File` 管理导入、SVG 导出及 Golden 存取；`Liberty` 和 `Cell Config` 分别管理库与类型定义，保留全局 Search、Compare/Single 切换及帮助入口。
- **上下文工具栏**：展示当前模块/实例与视图状态，提供历史、Whole/Focused、Fit view、View、Layout、Timing、Adjust、选中对象摘要和两侧面板开关。
- **Navigator**：左侧导航区以 `Hierarchy` / `Design` 页签组织模块实例树、筛选、实例上下文选择和设计统计。
- **Inspector**：右侧检查区保留对象摘要、Single 或 A/B 来源、完整名称与复制入口；以 `Connections` / `Timing` / `Adjust` 页签组织对象详情，清楚区分实例覆盖与 `Edit cell type…` 类型定义。
- **中央主画布**：最大化呈现交互式 SVG 原理图。
- **底部状态栏与抽屉**：集中展示解析/布局状态、provider 信息及 `Diagnostics` / `Log` 计数；诊断与过程日志在独立抽屉中查看。

Compare 配置行仅在对比时显示，位于画布上方；Focused roots 与 Fanin/Fanout 深度位于画布自己的上下文行。全局设置不混入对象详情。

**设计底线**：不设营销落地页，不堆砌大面积装饰插画，不用冗长的解释性空话挤占主画布空间。

## 视觉风格规范

- **背景与配色**：画布与面板背景采用适合长时间读图的中性低饱和色调；逻辑门（gate）、端口（port）与导线（wire）通过清晰的色彩层级区分结构语义，避免使用单一高饱和色系铺满界面。
- **字号与排版稳定性**：界面控件文本字号保持恒定，不随画布视口宽度缩放；按钮、输入框与工具栏保持固定高度，杜绝因鼠标悬停（hover）或动态文本更新引发界面布局跳动。
- **卡片克制使用**：卡片容器仅用于属性详情分组、重复列表项或弹出对话框，避免将页面区域做成立体层叠的套娃式卡片。
- **桌面适配**：宽度至少 1600px 时 Navigator 与 Inspector 默认停靠；1280–1599px（包含 1366/1440）默认保留 320px Inspector，Navigator 以抽屉打开；低于 1280px 时两者均为按需抽屉，同一时刻只打开一个。1920px 下默认宽度分别为 240px / 336px。停靠面板可调宽，Navigator 范围 220–360px、Inspector 范围 320–560px；用户显式选择优先于默认值。
- **局部溢出**：Inspector 对象摘要与页签在滚动详情时固定可见；超长摘要限制高度并允许局部滚动，长对象名仍可完整查看与复制。时序表在自身容器内横向滚动。连接及层次表按每页 100 行分页，关联目标列表按每页 20 项分页，不裁剪底层模型。窄于 760px 的窗口提示加宽使用完整工作台。

## 交互行为规范

### 1. 画布操作与布局

- 支持鼠标滚轮以指针为中心缩放，支持按住空白区域拖拽平移。
- 支持一键适配视口（`Fit view`），支持选中对象后一键居中放大（Inspector 的 `Zoom to selection` / 快捷键 `F`）。
- 支持将当前视图导出为自包含的离线 SVG 文件。
- 支持 `AnchorLayered`、`ELK`、`Simple` 布局引擎在线切换：默认使用 `AnchorLayered`，失败时按 `AnchorLayered → ELK → Simple` 顺序自动降级；用户主动取消任务不触发降级，最终失败后停止重试。异步布局与渐进式分批渲染通过底部状态栏实时汇报进度。
- 大规模模块不再采用结构分组折叠（group collapse/expand），统一通过完整图（Whole）、搜索优先（Search-first）或局部聚焦（Focused）管理加载与可见范围。
- 当缩放倍率低于阈值（`0.65`）时，允许自动隐藏引脚名称、线网标签、单元元信息与时序文字以保证可读性与帧率，放大后自动恢复。
- 支持 `Adjust` 手工布局校准模式：开启后可直接拖拽移动单个原理图节点（普通浏览模式下拖拽画布仍为平移视口）。
- `AnchorLayered` 与 `ELK` 下的手工校准均采用“自动布局基底 + 手动覆盖（override）”混合机制：未移动的节点保持原自动布局坐标，被移动节点的关联导线自动执行正交避障重布线。`Layout > Reset view overrides` 清除位置、尺寸、实例属性、引脚方向与不布线 net 覆盖；Compare 中同时作用于 A/B。
- 手工校准模式支持网格吸附（Grid snap）以及与相邻引脚的水平（$Y$ 轴）对齐吸附，便于快速将导线调整为水平直连或简洁短折线。
- 面板开关与调宽保持当前图中心和阅读比例，只提交视口调整，不触发布局或新增视图历史。界面偏好独立于网表 session 与 Golden 存储；非法或不可用的偏好存储回退至默认值。

### 2. 搜索定位

支持跨模块搜索以下五类对象：
- `module`（模块）
- `port`（端口）
- `net`（线网）
- `instance`（单元实例）
- `cell type`（单元类型）

搜索结果激活后：
- 高亮目标对象并将其居中显示于画布视口。
- 在 Inspector 同步展示该对象的完整属性与连接详情。
- 已绘制对象只定位；尚未绘制的 cell/net 按既有规则追加到 Focused roots。显式 `Add to Focused` 保留已有 roots，`Replace roots` 替换全部 roots；不得混淆这三种操作。

### 3. 对象选择与多级高亮

点击画布对象后的默认响应：
- **单击单元（Gate / Cell）**：选中该单元，展示其引脚方向、连接线网及直接扇入/扇出对象。
- **单击线网（Net / Wire）**：选中该线网，高亮整条物理连接树并展示驱动源（driver）与负载端（loads）。
- **跨层连接区分**：Inspector 的 `Connections` 页签将连接关系明确划分为 `Connections / Current module`（当前模块内部连接）与带强调底色的 `Hierarchy / Parent occurrence`（经由当前模块输入/输出边界延伸至明确父层实例的连接）。顶层模块无父实例，不显示 `Hierarchy` 区；子模块实例（`hinst`）的内部引脚不属于向父层延伸的连接，用户可通过**双击子模块实例**进入对应的子模块实例上下文。
- **快速锥体追踪**：双击输出端口或关联线网可快速查看扇入逻辑锥（Fanin cone）；双击输入端口或关联线网可快速查看扇出逻辑锥（Fanout cone）。

画布高亮样式支持正交叠加：
- `selected`（当前选中）
- `fanin`（扇入路径）
- `fanout`（扇出路径）
- `search-hit`（搜索命中）
- `compare-diff`（模块对比差异）

### 4. Compare 作用域

- A/B 为稳定身份：A 对应上方或左侧，B 对应下方或右侧；`Split` 只改变分屏方向。配置草稿在 `Apply` 后生效，Inspector 标明实际选中对象所属侧与模块。
- 两侧 roots、选择、视口和实例覆盖独立；`Sync pan / zoom` 与 `Sync Focus roots` 分别控制视口及根同步，不互相代替。
- `Focused` 以活动侧为起点，Fanin/Fanout 深度为两侧共享设置；`Whole` 清除两侧 roots 和 Output cone，`Fit view` 适配两侧，`Reset view overrides` 清除两侧覆盖。
- `File > Export SVG` 与 `Save Golden` 仅在 Single 可用；加载 Golden 会退出 Compare 并恢复对应的 Single 工作区。

## 原理图（Schematic）绘制规范

- **信号流向**：默认采用从左到右（left-to-right）分层排布；主输入端口（PI）置于左侧，主输出端口（PO）置于右侧。
- **引脚朝向**：单元输入引脚默认排布在左侧（或上下控制端），输出引脚默认排布在右侧。
- **逻辑门符号**：支持在标准矩形框与约定逻辑门符号之间切换；对于 `NAND`、`NOR`、`INV`、`XNOR` 等反相输出引脚绘制反相小圆圈（bubble）。
- **未知单元表示**：未识别单元统一使用矩形黑盒（blackbox）表示，清晰标注其 `cell type` 与 `instance` 名称。
- **线网标签排布**：线网名称标签默认贴近关联引脚放置（优先靠近目标单元的输入引脚），避免悬空漂浮在长导线中段。
- **高扇出简化**：扇出数较大的同源线网支持汇聚为共享中继节点（Fanout hub）。
- **正交走线优先级**：导线布线优先采用局部水平直连与短折线（dogleg），仅在跨越多层或局部通道严重拥塞时才借用外围全局通道（outer lane）。

## 可访问性与可读性要求

- 文本标签与节点外框、导线之间必须经过碰撞检测，防止不可控重叠遮挡。
- 任意合法缩放倍率下，显示的文字均须保持清晰锐利。
- 状态与差异区分不得仅依赖颜色单一维度，需配合线宽加粗、虚实线型或边框样式变化。
- 所有纯图标按钮均须提供明确的文字提示（Tooltip / `aria-label`）。
- `/` 在非编辑状态下聚焦搜索，`F` 定位所选对象，已有历史快捷键保留；输入框、输入法组合与模态对话框中的编辑不被全局搜索快捷键打断。
- 菜单与抽屉可用 Escape 收起并归还焦点；页签支持方向键、Home/End，停靠面板分隔条支持左右方向键按 16px 调宽。

## Liberty 导入交互

全局栏 `Liberty` 展开独立浮层，提供 Load .lib、扫描期间 Cancel import 和 Unload。复用工具栏展开/互斥、点击外部及 Escape 收起行为；收起仅隐藏面板，不取消导入或卸载库。摘要显示文件、cell 数与告警数，文本安全写入。文件选择、拖放和非输入区粘贴走同一导入用例。新导入准备完成前保留上次有效库；语法失败不清空旧快照。提交后刷新活动 Single/Compare 工作区，保留既有视口与显式布局覆盖；刷新失败与库解析失败分别报告。库来源与原始 function 在 Inspector 中可见；缺失接口和配置冲突在 Diagnostics 中可见。页面刷新需重载库。
