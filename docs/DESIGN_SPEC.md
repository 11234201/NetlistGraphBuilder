# 界面与交互设计规范

## 产品体验原则

本项目是面向芯片综合与验证工程师的专业分析工具，而非营销展示页。打开页面后的第一屏即直接进入可操作的工作台：

- **全局栏**：`File` 管理导入、SVG 导出及 Golden 存取；`Settings` 集中显示、布局、时序、Liberty 库和单元定义，保留全局 Search、Compare/Single 切换及帮助入口。
- **上下文工具栏**：展示当前模块/实例与视图状态，提供历史、Whole/Focused、Show Path、Fit view、Adjust、选中对象摘要和两侧面板开关。
- **Navigator**：左侧导航区以 `Hierarchy` / `Design` 页签组织模块实例树、筛选、实例上下文选择和设计统计。
- **Inspector**：右侧检查区保留对象摘要、Single 或 A/B 来源、完整名称与复制入口；以 `Connections` / `Timing` / `Adjust` 页签组织对象详情，清楚区分实例覆盖与 `Edit cell type…` 类型定义。
- **中央主画布**：最大化呈现交互式 SVG 原理图。
- **底部状态栏与抽屉**：集中展示解析/布局状态、provider 信息及 `Diagnostics` / `Log` 计数；诊断与过程日志在独立抽屉中查看。

Compare 配置行仅在对比时显示，位于画布上方；Focused roots 与 Fanin/Fanout 深度位于画布自己的上下文行。全局设置不混入对象详情。

**设计底线**：不设营销落地页，不堆砌大面积装饰插画，不用冗长的解释性空话挤占主画布空间。

## 视觉风格规范

- **背景与配色**：画布与面板背景采用适合长时间读图的中性低饱和色调；逻辑门（gate）、端口（port）与导线（wire）通过清晰的色彩层级区分结构语义，避免使用单一高饱和色系铺满界面。
- **字号与排版稳定性**：界面控件文本字号保持恒定，不随画布视口宽度缩放；按钮、输入框与工具栏保持固定高度，杜绝因鼠标悬停（hover）或动态文本更新引发界面布局跳动。
- **卡片克制使用**：卡片容器仅用于属性详情分组、重复列表项或弹出对话框，避免将页面区域做成立体层叠的套娃式卡片。
- **桌面适配**：宽度至少 1600px 时 Navigator 与 Inspector 默认停靠；1280–1599px（包含 1366/1440）默认保留 320px Inspector，Navigator 以抽屉打开；低于 1280px 时两者均为按需抽屉，同一时刻只打开一个。1920px 下默认宽度分别为 240px / 336px。停靠面板可调宽，Navigator 范围 220–360px、Inspector 范围 320–560px；用户显式选择优先于默认值。
- **局部溢出**：Inspector 对象摘要与页签在滚动详情时固定可见；超长摘要限制高度并允许局部滚动，长对象名仍可完整查看与复制。时序表在自身容器内横向滚动。连接及层次表按每页 100 行分页，关联目标列表按每页 20 项分页，不裁剪底层模型。窄于 760px 的窗口提示加宽使用完整工作台。

## 交互行为规范

### 1. 画布操作与布局

- 支持鼠标滚轮以指针为中心缩放，支持按住空白区域拖拽平移。
- 支持一键适配视口（`Fit view`），支持选中对象后一键居中放大（Inspector 的 `Zoom to selection` / 快捷键 `F`）。
- 支持将当前视图导出为自包含的离线 SVG 文件。
- 支持 `AnchorLayered`、`ELK`、`Simple` 布局引擎在线切换：默认使用 `AnchorLayered`，失败时按 `AnchorLayered → ELK → Simple` 顺序自动降级；用户主动取消任务不触发降级，最终失败后停止重试。异步布局与渐进式分批渲染通过底部状态栏实时汇报进度。
- 大规模模块不再采用结构分组折叠（group collapse/expand），统一通过完整图（Whole）、搜索优先（Search-first）或局部聚焦（Focused）管理加载与可见范围。
- 当缩放倍率低于阈值（`0.65`）时，允许自动隐藏引脚名称、线网标签、单元元信息与时序文字以保证可读性与帧率，放大后自动恢复。
- 支持 `Adjust` 手工布局校准模式：开启后可直接拖拽移动单个原理图节点（普通浏览模式下拖拽画布仍为平移视口）。
- `AnchorLayered` 与 `ELK` 下的手工校准均采用“自动布局基底 + 手动覆盖（override）”混合机制：未移动的节点保持原自动布局坐标，被移动节点的关联导线自动执行正交避障重布线。`Layout > Reset view overrides` 清除位置、尺寸、实例属性、引脚方向与不布线 net 覆盖；Compare 中同时作用于 A/B。
- 手工校准模式支持网格吸附（Grid snap）以及与相邻引脚的水平（$Y$ 轴）对齐吸附，便于快速将导线调整为水平直连或简洁短折线。
- 面板开关与调宽保持当前图中心和阅读比例，只提交视口调整，不触发布局或新增视图历史。界面偏好独立于网表 session 与 Golden 存储；非法或不可用的偏好存储回退至默认值。

### 2. 搜索定位

支持跨模块搜索以下五类对象：
- `module`（模块）
- `port`（端口）
- `net`（线网）
- `instance`（单元实例）
- `cell type`（单元类型）

搜索结果激活后：
- 高亮目标对象并将其居中显示于画布视口。
- 在 Inspector 同步展示该对象的完整属性与连接详情。
- 已绘制对象只定位；尚未绘制的 cell/net 按既有规则追加到 Focused roots。显式 `Add to Focused` 保留已有 roots，`Replace roots` 替换全部 roots；不得混淆这三种操作。

### 3. 对象选择与多级高亮

点击画布对象后的默认响应：
- **单击单元（Gate / Cell）**：选中该单元，展示其引脚方向、连接线网及直接扇入/扇出对象。
- **单击线网（Net / Wire）**：选中该线网，高亮整条物理连接树并展示驱动源（driver）与负载端（loads）。
- **跨层连接区分**：Inspector 的 `Connections` 页签将连接关系明确划分为 `Connections / Current module`（当前模块内部连接）与带强调底色的 `Hierarchy / Parent occurrence`（经由当前模块输入/输出边界延伸至明确父层实例的连接）。顶层模块无父实例，不显示 `Hierarchy` 区；子模块实例（`hinst`）的内部引脚不属于向父层延伸的连接，用户可通过**双击子模块实例**进入对应的子模块实例上下文。
- **快速锥体追踪**：双击输出端口或关联线网可快速查看扇入逻辑锥（Fanin cone）；双击输入端口或关联线网可快速查看扇出逻辑锥（Fanout cone）。

画布高亮样式支持正交叠加：
- `selected`（当前选中）
- `fanin`（扇入路径）
- `fanout`（扇出路径）
- `search-hit`（搜索命中）
- `compare-diff`（模块对比差异）

### 4. Compare 作用域

- A/B 为稳定身份：A 对应上方或左侧，B 对应下方或右侧；`Split` 只改变分屏方向。配置草稿在 `Apply` 后生效，Inspector 标明实际选中对象所属侧与模块。
- 两侧分别保存 roots、选择、视口和实例覆盖。`Sync pan / zoom` 联动平移和缩放，`Center match on click` 在选择对象时居中对侧当前图中的同名对象，`Sync Focus roots` 联动匹配 cell 的根操作。三个开关各自生效。
- `Focused` 以活动侧为起点，Fanin/Fanout 深度为两侧共享设置；`Whole` 清除两侧 roots 和 Output cone，`Fit view` 适配两侧，`Reset view overrides` 清除两侧覆盖。
- `File > Export SVG` 与 `Save Golden` 仅在 Single 可用；加载 Golden 会退出 Compare 并恢复对应的 Single 工作区。

## 原理图（Schematic）绘制规范

- **信号流向**：默认采用从左到右（left-to-right）分层排布；主输入端口（PI）置于左侧，主输出端口（PO）置于右侧。
- **引脚朝向**：单元输入引脚默认排布在左侧（或上下控制端），输出引脚默认排布在右侧。
- **逻辑门符号**：支持在标准矩形框与约定逻辑门符号之间切换；对于 `NAND`、`NOR`、`INV`、`XNOR` 等反相输出引脚绘制反相小圆圈（bubble）。
- **未知单元表示**：未识别单元统一使用矩形黑盒（blackbox）表示，清晰标注其 `cell type` 与 `instance` 名称。
- **线网标签排布**：线网名称标签默认贴近关联引脚放置（优先靠近目标单元的输入引脚），避免悬空漂浮在长导线中段。
- **高扇出简化**：扇出数较大的同源线网支持汇聚为共享中继节点（Fanout hub）。
- **正交走线优先级**：导线布线优先采用局部水平直连与短折线（dogleg），仅在跨越多层或局部通道严重拥塞时才借用外围全局通道（outer lane）。

## 可访问性与可读性要求

- 文本标签与节点外框、导线之间必须经过碰撞检测，防止不可控重叠遮挡。
- 任意合法缩放倍率下，显示的文字均须保持清晰锐利。
- 状态与差异区分不得仅依赖颜色单一维度，需配合线宽加粗、虚实线型或边框样式变化。
- 所有纯图标按钮均须提供明确的文字提示（Tooltip / `aria-label`）。
- `/` 在非编辑状态下聚焦搜索，`F` 定位所选对象，已有历史快捷键保留；输入框、输入法组合与模态对话框中的编辑不被全局搜索快捷键打断。
- 菜单与抽屉可用 Escape 收起并归还焦点；页签支持方向键、Home/End，停靠面板分隔条支持左右方向键按 16px 调宽。

## Liberty 导入交互

从全局栏 `Settings` 展开 `Liberty` 分区，提供 Load .lib、扫描期间 Cancel import 和 Unload。复用工具栏展开/互斥、点击外部及 Escape 收起行为；收起仅隐藏面板，不取消导入或卸载库。摘要显示文件、cell 数与告警数，文本安全写入。文件选择、拖放和非输入区粘贴走同一导入用例。新导入准备完成前保留上次有效库；语法失败不清空旧快照。提交后刷新活动 Single/Compare 工作区，保留既有视口与显式布局覆盖；刷新失败与库解析失败分别报告。库来源与原始 function 在 Inspector 中可见；缺失接口和配置冲突在 Diagnostics 中可见。页面刷新需重载库。

## AIG 图形与工作台（2026-11-15）

AIG 首版通过 File → Open AIG 使用现有 Single 画布与响应式两侧栏。输入格式为 ABC AIG DOT / 平坦组合 AND-NOT BLIF，采用 BT Graphviz 曲线：PI 正三角、PO 倒三角、AND 椭圆；PI/PO 使用源端口名，BLIF 注释映射保存在信息栏、Names 页与搜索索引中。工具栏 View 默认 Logic View（原 ABC），让输入、输出靠近各自关联逻辑自然分层。Standard 按逻辑深度分层。两种模式统一使用 Arial 12 字体、浅蓝输入、浅绿输出、深灰轮廓与灰色连线，反相边均为虚线，分析与选中高亮使用同一策略。仅布局方式不同；两种视图保留同一拓扑与对象身份，切换失败或取消保留旧图。

关键节点红色填充、关键边红色加粗、扇出橙色边框与选中对象紫色外框可叠加。Logical critical path 与 High fanout 默认关闭，用户显式开启后随工作区恢复。Highlight connections 在 AIG 中提供 Off、All 和指定级数，默认为 All。点击输出端口以蓝色向输入或常量追踪，点击输入端口以绿色向输出追踪。在同一控件中指定正整数 N 时最多追踪 N 条连续的有向连接，范围外的节点与连线灰显。清除选择或关闭连接高亮后恢复。选中内部 AND 时，沿扇入（蓝色）与扇出（绿色）分别追踪相同级数，选中边时标记其两个端点。深度、选区和分析开关只更新图元属性。视图样式切换才重新布局。样式、连接高亮设置和选区随工作区恢复，SVG 导出使用相同展示策略。Netlist 不启用该邻接高亮。

同一 AIG 的样式切换保留搜索内容、侧栏滚动位置与键盘焦点；布局完成时不替换侧栏输入框，保留正在进行的输入法组合输入。准备新布局时 View 选择器保持可用，重新选择当前已显示图的样式会取消待完成的布局；失败或取消不会覆盖原图。调整连接高亮时只更新受影响的图元。

File → Open design 同时接受 Verilog 与 AIG 文件；Open AIG 及 Open design 的文件过滤器均包含 `.blif`、`.dot`、`.txt`。Paste AIG 对话框、非输入框 Ctrl+V 和拖放共享格式识别及导入生命周期。BLIF 文本可不带扩展名；导入失败保留原画布与对话框文本，更新请求取消旧计算。

File 下方按 Netlist + Timing 和 AIG + Level 分组。AIG 可与一份可选 Level 同时打开，也可在当前图补载或替换。输入 AT 改变下游逻辑层级和逻辑关键路径，节点与边的身份保持稳定。各点的报告指标在 Inspector 中查询，Level 附件随所属图恢复。[Level 文件规范](design/aig_level_format_spec.md)

Paste AIG 绘图前可选择 Standard / Logic View，初始默认 Logic View。粘贴窗口内显示处理进度与失败信息；处理期间禁用重复提交和源文本编辑，Cancel、关闭及 Escape 取消待完成的导入。Standard 布局超时后保留文本并提示选择 Logic View 重试；不自动更换视图样式或延长布局超时。

Verilog / Timing 粘贴取消会中止实际布局任务及尚未完成的绘制，取消或过期结果不得覆盖新请求。既有网表导入在布局前已应用解析结果，因此取消保留已解析的数据，清除当前取消操作的画布并明确提示可重新绘图；Single / Compare 使用共享的任务取消边界。

Navigator 提供 Design、Objects 和 Analysis，有 BLIF 映射时可从 Names 查看设计名、原始 ID、极性和用途。Inspector 的普通对象使用 Connections、Analysis 和 Source。全局搜索可以按原始 ID 或映射名定位节点。AIG 导入可选择 Search-first 先建索引，在选定邻域或路径后才调用 Graphviz。AIG Single 支持 Whole 和多根 Focused，两种样式与 SVG 导出共用当前显示范围，重收敛只使用范围内的真实逻辑。新文件或新的 Focused 布局准备成功后替换画布，失败或取消保留原视图。Compare、Timing、Liberty、Cell Config、Adjust、Golden 仍属于 Netlist 工作区。

Analysis 分为 Reconvergence 与 Blocks。前者列出拥有两条内部节点不相交路径的分叉/汇合对，点选后两条证明路径分别为蓝、橙，分叉与汇合外框为青色；详情按需计算相关路径并集。后者识别 XOR2/XNOR2/MUX2 的全部有限函数变体，列出根节点、边界输入、引脚映射、极性与外部用途；块成员及输入边界为紫色外框。保留原始 AIG，不折叠或替换节点。XOR/XNOR 按正相根函数命名；MUX 采用确定性的引脚/极性规范表示，出边取反不会重复计数。

Netlist Single、Compare 两侧及 AIG Single 均支持独立的 Show Path。双端查询保留所有合法连接，单端查询自动列出另一端的组合边界。报告按端点展示到本次所选终点（或 Auto ends）的剩余级数，以及从查询起点到该点的级数（From start）。两者都给出最短和最长值。Focused 和画法只改变可见范围，导出 SVG 附带当前查询和端点摘要。无路径、歧义、组合环及预算超限按各自状态报告。

Inspector 在正相根公式与引脚映射中统一展示等效输入极性。Root output uses 按接收端口或门输入槽列出该边传递的函数。MUX 的出边取反时翻转 D0、D1，保留选择信号。内部节点的外接支路单列。

点选分析结果不移动视口，Locate 单独定位，Clear highlight 清除分析选区。Block labels、Dim outside selected result 均默认开启。后者在选中块或重收敛结果时淡化外围节点与连线。邻接高亮在分析选区活动时暂时隐藏，反相虚线始终保留。无可用空位的块标签可省略，结果列表仍完整列出已发现块。分析首帧后异步运行，可取消和重试；达到预算时显示 Partial results 及原因，不能解释为全图不存在其它结果。详情与结果列表分页，任意大等价子图不作穷尽识别承诺。
